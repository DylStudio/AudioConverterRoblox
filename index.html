Cara mendapatkan API Key
  1. Buka Roblox Creator Hub dan buat API Key baru
  2. Beri nama, misalnya "DYL STUDIO"
  3. Aktifkan izin baca & tulis untuk Assets
  4. Tempel API key ke form di bawah lalu klik "Simpan"
Bisa ditemukan di URL profil Roblox kamu

Group Account Tutorial
  1. Buka pengaturan grup kamu di Roblox
  2. Masuk ke Creator Dashboard → Credentials
  3. Buat API key dengan izin baca & tulis (Assets:Read dan Assets:Write) untuk aktifkan deteksi moderasi
  4. Salin User ID dan Group ID kamu
  5. Tempel API key dan ID di bawah
